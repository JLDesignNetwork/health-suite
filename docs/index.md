# Health Suite — In-Repo Wiki

Health Suite is a local-first, zero-cloud household health, nutrition, and medical record management desktop app built on NativePHP + Laravel 13 + Livewire 4.

This `docs/` directory is the project's Single Source of Truth wiki (GitHub Wiki is disabled in favor of in-repo docs — see [`.github/` governance](../.github/)).

## Contents

- [`architecture.md`](architecture.md) — multi-tenancy/privacy model, household mode, onboarding, `HealthService` formulas, NativePHP runtime, and implementation history by phase.
- [`usage.md`](usage.md) — installation (packaged app), local development setup, running tests, and building the native app.
